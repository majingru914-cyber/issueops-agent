# IssueOps Agent v0.1.0

IssueOps Agent v0.1.0 是一个可运行、可测试、可评估、可部署的单 Agent 工程型 MVP Release。

## Highlights

- 使用 LangGraph `StateGraph` 实现 Analyze、Plan、Execute、Evidence、Review、Reflection、Re-plan 与 Final 闭环；
- 统一 typed Tool Schema、Registry、Runtime 和 `ToolResult`；
- 提供 Retry、Timeout、Fallback、错误分类和硬预算；
- 使用 SQLite 保存 Task、State Snapshot 和 Execution Trace；
- 通过 FastAPI 提供异步任务提交、查询、Trace、Status 与 Health；
- 使用 non-root Docker Image 与 named volume 部署。

## Architecture

```text
Client / CLI
→ FastAPI / Agent Runner
→ LangGraph Agent
→ ToolRuntime
→ Repository / GitHub Tools
→ TaskRecorder
→ SQLite
```

Evaluation 独立调用同一个 Agent Runner；Docker 只封装现有 FastAPI Service。

## Implemented Capabilities

- Repository directory/file/code search；
- GitHub Issue / Pull Request 只读查询；
- Evidence-grounded Draft 与 Final Answer；
- Reviewer、Reflection 和增量 Re-plan；
- bounded Retry、Timeout、Fallback 与 Tool budget；
- SQLite restart query；
- CLI、REST API、Docker 和 Demo Client。

- Case Pass Rate：95%；
- Task Success Rate：100%；

正式机器可读证据位于 `eval/reports/evaluation-report.json`。

## Deployment

```bash
docker build -t issueops-agent:v0.1.0 .
docker volume create issueops-data
docker run --rm -p 8000:8000 -v issueops-data:/app/data issueops-agent:v0.1.0
```

Release 验证结果：156 项 pytest 全部通过；两次 Evaluation correctness metrics 一致；Release Container 的 `/health`、`/status`、异步 Task、Poll 和 15-event Trace 均通过。Image size 为 297MB，进程以 non-root `issueops` 用户运行。

## Known Failure Case

`repo-007` 的 Production Error Code 为 `EXECUTION_FAILED`，Benchmark 期望 `INVALID_ARGUMENT`。任务终态与 Tool 选择正确，但错误分类不一致，因此保留为真实失败，不调整数据集换取满分。

## Known Limitations

- Planner 与 Reviewer 是规则实现；
- SQLite、线程池和 background registry 为单进程边界；
- 运行中任务在进程或 Container 崩溃后不会自动续跑；
- 无 Authentication、multi-worker、distributed queue 或 Cloud Deployment；
- Benchmark 规模有限且 GitHub 场景使用 Mock。

更多信息见 `README.md`、`docs/architecture.md`、`docs/evaluation.md` 和 `docs/failure_cases.md`。
